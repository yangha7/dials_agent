# DIALS PHIL Parameter Reference

This directory contains the **complete PHIL (Python Hierarchical Interface Language) parameter documentation** for all DIALS commands, obtained via `dials.program -c -e2 -a2`.

## How These Were Generated

Each file was generated by running:
```bash
dials.<program> -c -e2 -a2
```

The flags mean:
- `-c` — Show configuration/parameters (instead of running the program)
- `-e2` — Expert level 2 (show all parameters, including advanced/expert ones)
- `-a2` — Attributes level 2 (show parameter metadata: type, help text, defaults, constraints)

## How to Use

To view the full parameter documentation for any DIALS command yourself:
```bash
# Show all parameters with full metadata
dials.import -c -e2 -a2

# Show only expert-level parameters (no metadata)
dials.import -c -e2

# Show only basic parameters
dials.import -c
```

## PHIL Parameter Format

Each file uses the DIALS PHIL format:
```
parameter_name = default_value
  .help = "Description of what this parameter does"
  .type = int|float|bool|str|choice|path|...
  .expert_level = 0|1|2
```

- **expert_level 0**: Basic parameters (shown by default)
- **expert_level 1**: Advanced parameters
- **expert_level 2**: Expert/developer parameters

Parameters can be set on the command line:
```bash
dials.find_spots imported.expt spotfinder.threshold.dispersion.sigma_strong=4.0
```

Or via a PHIL file:
```bash
dials.find_spots imported.expt params.phil
```
